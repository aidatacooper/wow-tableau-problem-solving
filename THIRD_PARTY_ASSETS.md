# Third-Party Assets

The AGPL-3.0-or-later license applies to original project code and
documentation. It does not relicense third-party materials.

Downloaded blog posts, Tableau Public workbooks, screenshots, sample datasets,
brand names, and trademarks remain subject to their respective owners' terms.
Generated `posts/`, `dashboards/`, and `dataset/` directories are ignored by
Git and should be regenerated locally.

A contributed iteration should include only the minimum extracted data and
evidence needed for reproducible testing. Contributors are responsible for
confirming that those assets may be redistributed. When permission is unclear,
record the source URL and SHA-256 hash instead of committing the asset.
