## 备注 / 已知坑

- 作者文章正文说 Misc 由 3 个 Sub-Category 组成，作者工作簿实际是 5 个
  （Art、Envelopes、Fasteners、Labels、Supplies）。按工作簿（也就是发布视图）重建。
- `table_calc` 的 `ordering-field` 必须写成列引用形式（`[ds].[tmn:...]`），
  直接把 `MONTHTRUNC(Order Date)` 写进字段级 `<calculation><table-calc>` 会让
  XSD pattern 校验失败；因此字段级只声明 `table_calc="Rows"`，月份寻址交给
  `configure_layered_chart(table_calc_overrides=...)`。
- Set 的颜色要同时写 compound palette（set × Sub-Category），单字段 palette 只是
  图例回退；作者的 encoding key 正是 `[io:...Set:nk]\n[Sub-Category (group)]`。
- `configure_worksheet_style(size_style={"type": "catsize", ...})` 是公共 API，
  不要手写 `style-rule` XML（builder 阶段边界不允许）。
