## 关键坑（已规避）

1. 计算日期以 caption 形式进 shelf 会留下未解析的 table-calc/ordering-field，
   Cloud 渲染空白。本 case 全部嵌套依赖都写成真实字段实例，构建产物中
   `table-calc` 与 `ordering-field` 计数均为 0。
2. layered pane 的轴必须同时出现在 shelf 表达式里（两个
   `EXACTDATE(...)` 都在 cols 上），否则 sheet 空白。
3. `cwtwb` 对未知 caption 会按字符串猜类型；因此用直通别名
   （`Created At` 等 7 个 `[physical]` 计算字段）承载显示名。
4. `axis_style` 只接受 `encodings`/`per_field`；把 `range-type`/`min`/`max`
   当 format 写会违反 XSD（Key 的 0–1 固定轴改用 `encodings`）。
5. 复用模板数据源（`set_hyper_connection`）而不是 `add_hyper_datasource`，
   产物只含一个数据源和 Hyper，不再打包模板 xls。副作用是数据源 caption
   仍是 `Sample _ Superstore (Simple)`（`cwtwb` 无公共 caption setter），
   记为外观差异。
6. 参考带的端点若是裸数字，在 datetime 轴上会被当成 1899 序列值；改用两个
   datetime 字段（`Working Hours Start/End`）+ min/max 带，端点保持真实时刻。
7. `configure_worksheet_style(panes_style=...)` 的 dict 键是 pane id，
   无 id 的 pane 要用 list 形式，否则 Data 的标签开关静默失效。
