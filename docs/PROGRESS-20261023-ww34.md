## 已知 SDK 缺口 / 本地 workaround（未改 SDK，未开 issue）

1. `set_hyper_connection` 把不含 id/code/zip 的 integer 列登记为 measure，且裸 `Week`
   会被日期名启发式绑成 `MONTH(Week)`。→ builder 用显式离散计算字段
   `Season` / `Week` / `Player Id` 加连续 `Week Number`（供 in-range 过滤）。
2. `configure_chart` 的 Rows 嵌套是 `Team * (Current * Consecutive)`，
   作者的是 `Team / (Current * Consecutive)`。→ 改用
   `configure_layered_chart(axis_shelf="columns")`。

两处都记在 `analysis.md`、`case.yaml.workarounds`、`evidence/sdk-baseline.json`，
`capability_gaps: []`、`related_cwtwb_issues: []`。
