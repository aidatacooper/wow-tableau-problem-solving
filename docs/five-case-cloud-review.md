# Five additional cases: Cloud REST and artifact review

These five independent `TWBEditor("")` builds extend the active catalogue from 20 to 25 cases. Each is accepted as `replicated / acceptable_delta` within Cloud REST image/data states and workbook artifact contracts. They are not pixel-identical copies. Browser clicks, brushing, hover and live Explain Data execution were not performed.

The tested SDK is [0958b51](https://github.com/aidatacooper/cwtwb/commit/0958b51e18cd3120a2f67fd7dbcc7e978a105399), pinned in `requirements.txt`. Generic improvements and their source cases are documented in [case-driven SDK enhancements](https://github.com/aidatacooper/cwtwb/blob/main/docs/case-driven-enhancements.md). SDK regression validation: 453 passed, 25 skipped. Each case includes input locks, independent data verification, captured image/CSV hashes and a visual review.

For each row, the corresponding iteration's `evidence/visual-review.md`, `evidence/cloud-data-comparison.json` and `evidence/cloud-verification.json` give the exact scope, differences and hash binding. The reviewed workbooks were frozen before final exports. Validation rebuilds run in disposable copies so they do not replace accepted files or invalidate capture hashes.

`scripts/capture_case_cloud.py` publishes and exports using process-environment credentials; the non-secret request manifest records workbook paths, view names, parameter/filter states and CSV scope. No PAT is stored in the scripts, workbook packages, metadata or evidence.

Windows reproducibility fixes preserve UTF-8 text decoding during case validation and prevent Git line-ending conversion of hash-bound REST CSV exports. The earlier WW31 input grouping reader now explicitly uses UTF-8. Existing accepted workbooks and screenshots remain frozen.

Final validation: 55 shared unittest checks passed; all 25 active cases passed catalogue validation and independent disposable rebuilds using the pinned SDK Git installation. SDK CI passed: [run 37019820792](https://github.com/aidatacooper/cwtwb/actions/runs/37019820792).
