# Intermediate heatmap with conditional labels

Donna Coles' article was published on 18 July2020. The official2020week29 challenge was published14July2020 (WordPress post3860). The target is her `2020_07_15_WW29_Heatmap_Intermediate` dashboard and `Chart-Int` worksheet. Her Advanced click-row/column version has unresolved bugs explicitly discussed in the article, so it is excluded from replication and acceptance.

The locked four-column extract contains9994 Superstore order-line records dated2016–2019: OrderDate, Quantity, Sales and Profit. The visual is twelve calendar months by four years, coloured by average line-item quantity, with native row/column totals. No orders/customers are inferred from these reduced source columns.

Two labels coexist on each square. `Total Label` returns `AVG(Quantity)` when either independently addressed SIZE is1; thus total row/column labels remain visible. `Cell Label` returns AVG only when both hover sets include that month/year and both SIZEs exceed1. SIZE Years addresses the year dimension; SIZE Months addresses the month dimension inside both parent label calculations. The sets start empty. Two on-hover assign actions populate them from Chart-Int; clearing excludes all members. These events, source, target and clearing semantics are validated in the artifact; no browser hover or click execution is claimed.

The colour measure carries the original `visual-totals=Avg` configuration. Its visual average over contributing aggregate cells can differ from the weighted raw-row AVG used by the total-label calculation:2016 has weighted AVG3.8038133467 versus equal-month average3.7752638356. The verifier retains both independent numerical expectations rather than assuming totals are sums or averages of already rounded text. ProfitRatio uses SUM Profit/SUM Sales at each cell's scope.

The builder starts with `TWBEditor("")` and reads only the extracted input Hyper. Existing generic public APIs provide independently nested table-calc addressing, empty sets, set actions, native visual totals and include-totals colour. The month caption is DATENAME; a negative month-number computed sort preserves the author's January–December order. The dashboard retains900×500 dimensions, title underline, continuous teal-blue legend, totals whitespace and the original design/recreation credits. Source files and analysis-only export copies remain under scratch.

Cloud acceptance requests default, year2019, January, and their single-cell intersection. Ordinary REST filters test reduced-domain SIZE branches but do not simulate hover selection. Each state exports the complete Chart-Int worksheet rather than a button CSV. The independent verifier recomputes the entire48-cell matrix and17 raw totals, validates every exported cell and explicitly records whether native totals actually appear in CSV. All PNG, CSV, author comparison and replica hashes are checked against the capture manifest.

The analysis-only author comparison changes only worksheet-window hidden attributes. Datasources, calculations, actions, dashboards and packaged data are verified unchanged; `evidence/export-provenance.json` binds the original and comparison hashes.
