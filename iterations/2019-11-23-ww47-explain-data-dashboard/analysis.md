# High level sales and saved Explain Data views

Donna's article was published 2019-11-23; official challenge WordPress post 3041 was published 2019-11-20. The author TWBX remains analysis-only under ignored dashboards/. The replica builder starts with TWBEditor("") and reads only the extracted Orders Hyper.

The primary 1000x800 dashboard compares 17 subcategories in three aligned charts: quarterly sales trends, latest-year sales bars with prior-year per-cell reference lines, and order-level sales dots with average order sales reference lines. The extract covers 2015 through 2018, so the computed latest year is 2018, irrespective of the challenge identity year. The latest-year sales total is $733215.2552. There are 271 nonempty quarter/subcategory groups; one of the potential 272 quarters has no orders, which is not fabricated as zero. The independent oracle checks all 9994 rows, each quarterly/year subtotal, every order/subcategory point, and category average record sales.

The second dashboard rebuilds the author's two saved explanation sheets: average record sales by order/subcategory and average sales by category. This recreates saved chart definitions, not Tableau's live statistical Explain Data engine. The user has explicitly accepted Cloud REST images/data states and artifact contracts. No lightbulb click or live explanation request is claimed. The static explanation sheets contain no hidden selection filters in the author package.

The author's RANDOM() function is unsupported by Tableau's published function contract. The replica uses deterministic ((INT(RIGHT([Order ID],6))*7919)%997)/997 jitter through supported public APIs. Jitter is consistent within an order. Horizontal sales positions and populations can match exactly; vertical positions intentionally differ and should be documented as acceptable delta after actual Cloud inspection. Native quarterly truncation is represented by a public date calculated field plus DAYTRUNC shelf, preserving quarter start positions.

Cloud CSVs must be requested separately for Trend, This Year v Last Year Bars, Jitter Dot Plot and the saved explanation sheets; a single dashboard CSV cannot prove all three data domains. evidence/data-contract.json stores complete independently computed expectations. All reference-line scope/value contracts and SDK save/reopen preservation are checked in verify_replication.py. Remaining work is Cloud image/data comparison. No visual-match claim yet.
