# WW34 — Top N on a Single Worksheet

Legacy semantically replicated case. It builds independent regional Top N sets,
an optional Other bucket, synchronized Bar and GanttBar axes, parameter
controls, and hover rank labels through a Set Action. It reuses packaged data
but does not use the author workbook as a build template.

The case predates the v1 metadata contract and is treated as legacy until its
source lock and analysis are migrated.
