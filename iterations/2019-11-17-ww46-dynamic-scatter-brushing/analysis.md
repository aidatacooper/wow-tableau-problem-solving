# Dynamic scatter and proportional brushing

Donna's article was published 2019-11-17; official challenge WordPress post 3032 was published 2019-11-13. The original filename says WW45 but the article, dashboard name and official page identify WW46. Original author workbook is analysis-only under ignored dashboards/. The builder starts from TWBEditor("") and reads extracted Hyper plus manufacturer categorical bins only.

The dashboard lets viewers choose Customer, Product or Manufacturer and independently choose Quantity, Sales, Orders or Discount for X and Y. Donna follows the official solution's Orders choice although the written challenge says Profit. The replica follows Donna's four options and makes no claim to add Profit. The initial state is Customer / Quantity / Discount. Three percentage bars partition the Selected LOD set; a select set action updates membership and clearing excludes all. This is validated as an artifact contract; no browser events are claimed.

The extracted dataset has 9994 rows, 793 customers, 1850 products, 5009 distinct orders, 37873 units, $2297200.8603 sales and 1561.09 summed discount. Manufacturer bins were extracted during analysis; escaped percent/hash/quote characters are decoded to actual product values. Ten refreshed product names have no author bin. The author calculation omits default, preserving their original values as ungrouped members; the SDK needed generic optional-default support. The builder calls add_group(default_value=None), with synthetic SDK regression coordinated by the main agent.

The numerical oracle aggregates all marks for 3 LOD states and all 16 X/Y combinations, and checks empty/five/all selection partitions. Distinct order count is computed separately for In and Out: the same order can cross a product/manufacturer partition, so it is not generally additive. SUM measures are additive. The full data oracle is evidence/data-contract.json; a dashboard CSV can contain only one sheet and cannot prove all scatter marks or bars. Use Scatter and each bar worksheet exports for Cloud coverage.

Cloud acceptance compares author/replica at default and Product/Sales/Orders parameter states. Remaining work is image comparison and state CSV review. Visual matching is not yet certified. The public source has no initially selected set members. Workbook output is outputs/replicated-workbook.twbx; top X scale uses synchronized dual columns with lower axis hidden.
