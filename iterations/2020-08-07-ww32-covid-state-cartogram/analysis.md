# COVID state trend cartogram

Article 2020-08-07; official 2020 WW32 published 2020-08-04 (WP 3916). Original 900x730 layout contains a single Map sheet with text and normalized area layers. The locked Hyper has 529,950 county/day fact rows. The builder never reads the original workbook and uses only public SDK APIs from an empty workbook.

The original CASE fields map 50 states and DC to an eight-row/twelve-column cartogram. Display dates are March 1 through July 31, 2020. The first six dates have NULL moving means, matching the native NullIfIncomplete setting. Seven-day moving means use WINDOW_AVG(SUM(new cases),-6,0), then divide by the maximum mean within each state. The date address is explicit on both nested window calculations. The state label is centered at May 16 at height 1.75; the blue area occupies height 0..1 and labels its maximum. Shared date and synchronized area/text domains keep states comparable in time while each state is normalized independently in magnitude.

The independent Hyper oracle sums county-level facts by state/day, computes every trailing mean and normalized series, and checks all 51 grid coordinates. The original Map REST CSV contains zero bytes and is not data evidence. Its existing Data sheet instead exports five measures per province/date. The default Data export independently covers all 7,803 mapped state/date keys, while the replica Map exports two mark-layer rows per key. Source Data REST state filtering currently converts the selected province to NULL rather than producing a valid single-state table, so filtered source Data is not accepted as proof. Final capture deliberately leaves source Data unfiltered for each state request and records the actual CSV filters. Replica California/Texas exports are checked independently against the locked raw Hyper; paired dashboard images retain the requested state filters for both roles. State filters are ordinary REST filters, not browser interactions. Final six-file CSV validation passed with the explicit original Data/replica Map scope, and all six paired images were reviewed as acceptable_delta. Remaining layout differences and the wrapped DC label are recorded in evidence/visual-review.md; the accepted artifact is frozen. The comparison export removes worksheet hidden-window attributes only; data, calculations, filters and layout are unchanged.
