# WW51 divergent histogram

Article date2020-12-18; official challenge date2020-12-16 (WordPress4174, challenge2020Week51). The original workbook is downloaded only to scratch for analysis and extraction. Its packaged Hyper is already pivoted: 5382 rows, 207 countries with male/female records in each of 13 years2000 through2012. The builder opens only that locked extracted Hyper through public SDK calls after TWBEditor(""). No additional pivot or derived input is necessary.

Viz is the sole business chart, default2012. For every nonnull age and sex, count distinct Country/Region. Female counts plot upward and male counts downward; the unsigned negative number format changes only display. Native breakdown is off so bars are unstacked. The age axis is continuous and fixed30..95. Female is originalpurple#a39fc9 and male originalteal#31a1b3. Field-based hidden reference lines use WINDOW_MAX(CountryCount) and its negative, both addressed across all visible ages and both sexes. These preserve the original reference formulas, whose positive maximum is the female peak. The all-year raw boundary audit finds male peaks larger than the female reference in 2001, 2002 and 2005; reference-domain mathematics alone does not prove actual Cloud axis clipping or asymmetry. The 2001 state is included as an explicit worst-boundary Cloud diagnostic. No formula is silently changed to an absolute maximum. They are included in the full exported business CSV and every value must match the independent raw oracle. Source min/max labels use range mode and match-color bold formatting. The final public-API styles reproduce those labels and correctly hide the count axis, title the age axis and draw the gray zero baseline and chart framing. Source hover content includes year, sex, age and country count; generated rich tooltip retains those fields and text, although no hover event is executed.

The author-export copy removes only existing hidden worksheet-window flags, with identical nonwindow businessXML and unchanged Hyper bytes recorded in export-provenance.json.
