# Sales versus goal with native relationships

Article date: 2020-07-10. Official challenge date: 2020-07-08, WordPress REST post 3848. The author packages 9,994 actual order-line rows and 534 independently keyed monthly goal rows. Actuals have Segment / Category / Subcategory / month grain; each goal is unique by Segment / Category / month. Actuals cover 2016–2019 and goals extend through December 2020. Only goal-only 2020 keys lack corresponding sales. The displayed period excludes 2016.

The builder creates two typed native logical Hyper tables from the extracted input and a three-key relationship. It never physically joins or preallocates goals. This generic SDK capability was absent from the released baseline and is tracked in sdk-baseline.json. The first development workbook successfully published to Cloud and its continuous line export preserved monthly goal grain; its discrete date shelves incorrectly collapsed years and the complete run was rejected and archived. The corrected builder binds explicit complete date expressions, and the verifier rejects month-of-year derivations. Final acceptance requires fresh exports bound to the corrected artifact.

Today is fixed at 2019-07-01. ACTUAL SALES includes complete months up to and including July 2019. A window maximum of distinct subcategory counts distinguishes true lowest-level views from sparse parent months: Home Office / Furniture in January 2018 has one subcategory but a window maximum greater than one, so it still retains its monthly goal. At true subcategory grain SALES GOAL is zero, formatted NO GOAL; RESULT is null and the plotted goal line is null. Table filtering drops future lowest-level months, including July, while the source's line calculation includes July actuals. These distinct conditions are intentionally preserved.

Four native worksheets reproduce the source scope: segment/month Table, expanded Data with record-retention flag, monthly actual/goal Line Graph, and monthly RAG Barcode. Three on-select field filter actions link the table to the line and barcode with show-all clearing. A native hierarchy supports Segment / Category / Subcategory drilling; actual browser expansion and action execution are not claimed. Full Data CSV supplies the independently verifiable lowest-grain scope that collapsed Table CSV cannot prove.

The independent verifier recomputes goals once from raw goal keys at every requested grain, actual sales from raw sales rows, all differences and ratios, threshold statuses, and monthly retention. REST scenarios are default, sparse Home Office / Furniture, Bookcases, and wider threshold values; all four sheets are exported for both roles. Comparison preparation only exposes hidden worksheet windows, preserving the author's formulas, layout and data. Fresh paired images and full data exports remain required before acceptance.

Data's native text crosstab completes every visible month for every existing dimensional partition. Independently derived domains contain 2,880 default cells, 235 sparse-category cells, and 105 Bookcases cells. Missing domain cells contain null financial values, zero distinct subcategories, the partition's independently computed window maximum, and a false retention flag. These empty cells are distinct from the 2020 goal-only records, which retain their raw monthly goal. The source's four full-sheet exports have passed this oracle in all states; the corrected replica must meet the same complete coverage.

The subsequent complete capture passed all 32 source/replica CSV comparisons and restored the original RAG and goal colors after removing unrelated cyclic table-calculation contexts. This was a case configuration error, not evidence of an SDK palette identity bug. It still exposed a varying per-month context subtitle in filtered states. The final title uses public EXCLUDE-month counts to summarize the selected dataset consistently across the worksheet. Bookcases therefore reports its actual Furniture category, whereas the author's filter descriptor remains Category: All because only Subcategory was explicitly filtered. This wording difference does not change the data selection or financial calculations.

The final title-corrected artifact passed all 32 fresh CSV comparisons at raw-decimal precision, complete monthly/domain coverage and context-title checks. All eight fresh images were independently inspected; goal and RAG colors match, filtered subtitles are readable, and remaining axis/padding/typographic/footer differences are documented as acceptable_delta in evidence/visual-review.md. Native actions and drilling are accepted only through the artifact contract; no browser events were performed. The final workbook remains frozen to its Cloud-bound hash.
