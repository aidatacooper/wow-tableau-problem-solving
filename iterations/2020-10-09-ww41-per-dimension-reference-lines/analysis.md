# Selectable measures and per-category references

Article date 2020-10-09; official 2020 WW41 challenge date 2020-10-07, verified from WordPress post 4019. These are the two business dates; challenge year and week identify the case. The locked original Hyper contains 9994 Superstore order lines. The builder starts with `TWBEditor("")`, reads only extracted input data, and uses public SDK APIs. Original TWB/TWBX content is analysis-only; the source comparison only exposes existing worksheet windows and records original/export hashes.

Three parameter states select Sales Per Order, Profit Ratio and Items Per Order. Quarterly sales per order is rounded to whole dollars, profit ratio after multiplication by 100 to one decimal, and items per order to two decimals. Each category reference equally averages its sixteen rounded quarter values. The Rank worksheets omit quarter, so their category metrics and ranking use rounded full-category aggregates instead. The independent verifier computes both grains directly from all original facts and verifies every exported quarter/reference cell and each complete rank card.

Two causes were separated by real Cloud probes. First, the SDK specific-dimension resolver stripped the continuous quarter instance to the raw date and emitted an instance rather than the raw Category ordering field. The generic native-reference correction restored all 48 quarterly points and all 48 window averages; it did not by itself restore the cards. Second, the original Square pane omitted the constant prefix/suffix dimensions addressed by the inner window calculation. Binding these with the public detail API restored all three ranking values. Final construction mirrors the author's simpler single Automatic pane per card, with size, Category colour and all labels bound together, no artificial constant axes, and local table-calculation contexts. This fills the card area and avoids the tiny clipped Square/Text overlays and their unwanted 0.5000 labels.

The continuous quarter axis uses public `QUARTERTRUNC(Order Date)`. A parameter-only Metric Label calculation on rows supplies the dynamic rotated metric name; no literal internal parameter reference appears on the axis. A transparent second Line pane supplies reference captions, and three field-backed coloured dotted reference lines supply geometry. Specific-dimension window addressing includes quarter and the bound constant label dimensions while partitioning Category; outer ranking addresses Category. The title and footer are left aligned through public text styles.

Final validation used cwtwb 0.27.1 at exact Git commit `eb1380d5da9c1b1bf1b306128cb8397150ba1a53`. All 24 Cloud CSVs and six paired PNGs for the three metric states passed independent review. The workbook is accepted as `acceptable_delta` with the full accepted hash and remaining visual differences recorded in [visual review](evidence/visual-review.md). The replica has slightly thinner strokes, different automatic quarter tick anchors, black reference captions at somewhat different offsets, and minor typography/footer spacing differences. All cards, extrema, values, units and dynamic metric labels remain readable and correct. No browser click, hover or tooltip execution is claimed. The failed initial captures remain separate diagnostic history and are not offered as accepted evidence.
