# Predicting the future — 2021 WW05

Article date 2021-02-04; official challenge date 2021-02-02 (WordPress post 4397). This challenge uses Tableau predictive modeling, not a replacement series of hardcoded future values.

The author's packaged Hyper contains 26 raw annual observations, 1993–2018: total enrollment and Black student enrollment at HBCUs. Extraction preserves the original Hyper bytes, bound by `inputs/source-lock.json`. The builder starts with `TWBEditor("")`, loads only that input and declares every calculation, chart, parameter, title, layout and action through public SDK APIs. It never reads the author workbook.

The string parameter `pSelect_Measure` selects total enrollment, Black student share, or non-Black student share. Actual values derive directly from the two raw enrollment columns. A native `MODEL_QUANTILE('model=gp',0.5,ActualValue,ATTR(DATETRUNC('year',Year)))` produces the median Gaussian-process prediction. The continuous annual date domain extends five years, through 2023, and enables calculations on densified marks. Actual values remain null for the five future years. Tooltip values express totals in thousands and ratios as percentages; residuals and title endpoint/direction values use the same addressed calculations.

The chart overlays an actual area with a predicted line. The side worksheet uses three Measure Names rows with Measure Values on detail and native bars to fill the selector cells. Its native parameter action fires on select, aggregates the selected name with ATTR, and retains the parameter when selection is cleared. The dashboard has only these two visible worksheets. These action contracts are verified from generated XML; no browser click is claimed.

The released fe9 SDK baseline lacked a public native time-series extension primitive. The generic SDK API `configure_worksheet_time_series` adds the future date domain and densified-mark calculation setting, with synthetic regression coverage. Existing date-expression grammar also requires exact brackets around integer `[Year 1]` when using it as a filter, because its name resembles a date expression.

Acceptance uses three actual REST parameter states and the entire Chart CSV. Each role exports 62 rows: two identical pane rows for each of 31 distinct years. The verifier checks this duplication contract, all 93 distinct date/metric prediction pairs against the source, all 78 raw training actual values independently, tooltip scaling, residual arithmetic, title endpoint values and direction. The native formula and extension contracts are separately verified. Gaussian-process hyperparameter fitting belongs to Tableau's engine; no independently reproduced GP fitting or numerical model oracle is claimed. Selector CSV is not proof of future values.

Author analysis files remain in ignored scratch storage. The comparison export only unhides worksheet windows for REST CSV access; its mutation scope and hashes are recorded in `evidence/author-export-contract.json`. Final Cloud evidence must match the exact final artifact hash and SDK Git installation provenance. Remaining visual differences are documented in `evidence/visual-review.json` after final paired-image review.
