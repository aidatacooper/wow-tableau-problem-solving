# Dynamic slicer filtering

Article date: 2020-12-04. Challenge identity: 2020 WW49. The published Donna workbook has four horizontal business charts: Region, Category, Segment and Ship Mode on a fixed 1190 x 900 dashboard. Every chart displays selected and omitted groups side by side, instead of discarding omitted facts. Three string parameters select a dimension; three dynamic all-domain sets track its selected members. The AND branch requires every membership, while the OR branch excludes inactive slicers. The metric parameter swaps SUM(Sales), SUM(Quantity) and COUNTD(Order ID).

The 9994 locked source rows contain nine business columns. The builder begins with TWBEditor("") and reads only this extracted Hyper file. The author archive is confined to scratch analysis/publication. The Cloud comparison copy exposes existing worksheets by removing hidden window attributes only; formulas, layouts, datasource contents and all other archive members remain unchanged.

Released Git e7fa lacked add_set(use_all=True); its existing omitted-members behavior creates an empty-level group. Explicitly enumerating the current parameter's domain would lose native dynamic all-domain membership. A generic API enhancement creates a native level-members group with all enumeration, covered by an author-free synthetic fixture. The case uses that public method for all three slicers.

Acceptance uses complete CSVs from all four business charts for default Sales/AND, Quantity/OR, Orders/AND and two active dimension-parameter Sales/OR states. Stored all-domain membership includes every fact at these REST states. These exports establish native set contracts and real parameter/metric execution; they do not execute interactive member selection. Independent raw subset oracles and an exhaustive active/membership truth table validate the intended AND/OR calculation separately. No ordinary REST filter is misrepresented as a set-member action. Paired REST images establish default desktop layout; no browser click, hover or mobile execution is claimed.

The source controls are checkbox multiselect dropdowns with an Apply button. Released e977 rejected checkdropdown mode, documented by an immutable synthetic probe and retained analysis fragment. Generic checkdropdown and show_apply support in immutable SDK df8c2a52cd48800fa0a43d936f6946d318f5b953 restores all three native controls; 844 SDK tests passed with 25 skips. Labels bind the currency prefix and metric after custom tooltip creation, preserving both native encodings.
