# 2021 WW07 — real Image Map Filter extension

Article date: 2021-02-18. Official challenge WP4501 date: 2021-02-16. The official title says 2020 Week 7 in error: its 2021w07tab slug, the 2021 article and author workbook establish challenge identity 2021 WW07. The original WP title is preserved in evidence.

The packaged Hyper contains two real logical tables: 969 emoji sentiment facts and 4,159 unique emoji dictionary keys. The published author workbook relates Emoji to emoji, rather than using the alternative codepoint relationship discussed in the article. Exactly 736 sentiment emoji match dictionary categories and 233 have null categories. People & Body and Smileys & Emotion form the categorical group Smileys & People; remaining categories pass through. This relational model and categorical group are rebuilt through public SDK APIs, without flattening or copying an author datasource.

Top 20 uses category as a native context filter before the top-20-by-occurrences filter, descending occurrence order, emoji/name/count headers, stacked positive/neutral/negative percentages, position circles and a one-unit baseline. The default category domain includes nulls, matching the original; a top-20 result need not contain twenty emoji when a category has fewer. Flags has only three matched sentiment emoji. The rounded category occurrence chart and average legend exclude null categories. Percentage measures divide sentiment sums by occurrence sums; average Position is unweighted by occurrence.

The actual external dashboard object is Image Map Filter, extension id com.tableau.extensions.junglebook.sandboxed, version 1.0.0, at https://extensions.tableauusercontent.com/sandbox/jungle-book/index.html. Its manifest declares minimum API 1.0, en_US localized name, Tableau author, icon and Configure menu, with no full-data permission. The runtime and gallery were publicly reachable during analysis. Locked structured manifest/settings JSON and extracted PNG resources supply the public generic extension API; no source TWB/TWBX/XML is a builder input.

The settings preserve configured=true, dimensions=[Group (group)], worksheets=[Top 20], imageDimensions=[259,413], scale-to-container mode 0, and eight original rectangle regions mapping the image to Smileys & People, Animals & Nature, Food & Drink, Activities, Travel & Places, Objects, Symbols and Flags. Every shape starts inactive. The image selection's intended filter target is only Top 20. There is no substitute native parameter presented as an extension.

The released fe9 SDK had no public extension authoring method; the SDK owner implements a reusable structured native dashboard extension API with synthetic tests. Acceptance is Cloud REST rendered layout/data plus native extension configuration/target/rectangle/resource contracts. REST category-filter states can independently exercise category data but do not execute the external app or prove its clicks. Network/runtime/site extension policy is checked separately from contract correctness; browser clicks, extension interaction or hovering are not claimed.


The initial real chart render exposed two generic filter bugs: exclude-mode metadata must live on the outer except expression, and a Python None categorical filter member must serialize as Tableau %null%, never as the string "None". The SDK fixes have synthetic tests. The repaired Avg and byGroup filters exclude the 233 null-category facts. Chart Measure Names colors bind the actual measure instances via public pane color_map, and the rounded-line category endpoints are ordered zero then occurrences for correct label placement.

Cloud REST category overrides have different meanings according to each original worksheet filter: Top20's inclusive context selects that category; Avg and byGroup's exclusive filters replace the null exclusion with that category exclusion, reintroducing the 233 unmatched null-category facts. The three dashboard PNG states render the default dashboard rather than visibly applying those worksheet CSV overrides. Thus the images prove default layout and extension rendering only; the category CSV states independently prove these inclusive/exclusive data scopes. Native extension settings establish only Top20 as the image-map target. No browser image selection or filtered-dashboard response was executed or claimed.

Final artifact-bound native/data verification passed for all 18 CSV files and six PNG hashes. The paired default dashboard is accepted with the deltas in evidence/visual-review.md.
