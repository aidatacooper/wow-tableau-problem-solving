# Quantity and profit ratio connected scatter

Article 2020-08-12; official 2020 WW33 WP 3929 published 2020-08-11 with matching title. The article link, workbook and footer mislabel WW34; those source labels do not establish the official identity. Source workbook name is preserved for paired comparison, while case metadata uses WW33.

The empty public SDK build uses only the locked 9,994-record Hyper. It groups 2018/2019 by Category and exact Month Year, yielding 72 points. Quantity is SUM(Quantity); Profit Ratio is SUM(Profit)/SUM(Sales). Circle marks remain visible for all categories. A folded Line layer plots Selected PR only for members of the native Selected Category set, with Month Year as the path. The initial set is empty, matching the original.

The native single-select assign action targets the category set and clearing excludes all members; Category highlighting is scoped to Scatter. The floating Insights panel filters the selected set and INDEX()=SIZE(), with explicit monthly window addressing. Its four extrema/date pairs use WINDOW_MAX/MIN and outer WINDOW_MAX to choose the last matching month when an extremum ties. The independent raw Hyper oracle verifies all 72 point quantities/ratios and every category's four extrema/date pairs.

REST scope is default 72 points and ordinary Category Technology/Furniture 24-point filters. These REST filters do not assign the set, so the initial Insights sheet remains empty and that empty CSV is not offered as proof of insights data. Set-event and dynamic-panel behavior is accepted through native calculation, action, target and clearing contracts; no click/hover event was executed. Source comparison only unhides existing worksheet windows. Final complete Scatter CSV verification passed all three states per role; all six paired images were reviewed as acceptable_delta. Empty initial-set Insights exports and the exact remaining visual differences are documented in evidence/visual-review.md. The accepted artifact is frozen.
