# Olympic ranking over time

Article 2020-08-01; official 2020 WW31 published 2020-07-29 WP 3903. Source 1000 x 700 dashboard contains the reversed top 10 bump chart and host strip, with three embedded tooltip targets. The locked Hyper contains 1,242 country/year medal totals, 33,203 athlete/medal rows and 28 host/year rows.

The empty public SDK build recreates three native logical tables and both original relationships (Host-Year to Medals-Year, and Medals-Year/Country to Medalists-Year/Country). Country weighted Score is 3 * Gold + 2 * Silver + Bronze. RANK_UNIQUE addresses the country and its mark-detail dimensions within Year; nullable top 10 values retain null years so lines do not connect over missing appearances. The second Shape layer uses host stars and country colors; other countries remain grey. The host strip carries full host score/medal counts and a red indication for hosts outside the top 10.

Medals and Top 10 Medalists Viz-in-Tooltip must filter by both Year and Country; the medalist target uses context filtering before top 10 athlete selection. Released SDK cbe200a rejects more than one VIT filter field. The saved baseline captures the error; root enhanced the generic API with native multi-field crossjoin and optional context filters, covered by synthetic tests. The candidate build uses only this public API, not a concatenated fake field. All SDK version/commit provenance is in metadata and final evidence.

The independent oracle covers every country medal count/score, permitted tie rank interval, host record and athlete medal group. Unique-rank ordering within equal scores can depend on native Tableau ordering, so ties are validated against score-derived rank intervals and unique top 10 ranks. Three REST states cover the full timeline and Year 2008/2016, with all five sheets exported independently. Tooltip event execution is checked through native embedding/filter contracts, not browser hover; full exported target data proves its own observed scope only. Source exports unhide existing worksheet windows without changing filters/calculations/data/layout. Final thirty-file CSV validation passed within the explicitly documented target-sheet scope, and all six paired images were reviewed as acceptable_delta. The host strip uses a quantitative alias with reversed public size range to retain visible negative X marks. The source Top 10 Countries target is empty outside its triggering tooltip and is not offered as data proof. Remaining visual differences are recorded in evidence/visual-review.md; the accepted artifact is frozen.
