# WW33 Problem Model

The user must compare regional performance across a dense formatted table while
retaining readable labels and threshold-driven emphasis. A conventional flat
text table cannot express the required paired label weights, multiple measure
panes, selected-versus-other bars, and row-level highlighting on one worksheet.

Required semantics are the calculations, threshold behavior, pane structure,
and selection behavior. Exact fonts, padding, and decorative borders are
presentation details unless they reduce readability.
