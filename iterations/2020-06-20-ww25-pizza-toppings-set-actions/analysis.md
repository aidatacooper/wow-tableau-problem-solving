# Pizza topping set actions

Article: Donna Coles, 2020-06-20. Official challenge: 2020 WW25, published 2020-06-16 (WordPress post 3766). The locked original and extracted inputs are identified in `inputs/source-lock.json`.

The build starts with `TWBEditor("")` and reads only the locked 26-product Hyper file and four extracted PNG icons. It creates exactly five worksheets on the original 800x500 canvas: type selector, product prices, selected-item list, selected total and budget status. Eight initial members total 17.54 pounds. The independent oracle checks every product price, type, vegetarian flag and selected member, plus budget 15/30/5 differences.

Two native menu set actions add and remove marks while keeping the set on clearing. The type selector filters the product chart through a native `Action(Type)` initialized to Size, so its initial selection can be replaced rather than intersecting a permanent ordinary Type filter. False/true filter mappings deselect selector/list marks. The custom shape palette API embeds the PNG data and Type mapping rather than depending on locally installed Tableau shapes. The released SDK 56377 baseline lacked shape embedding and native action-filter initialization; saved baseline evidence records those failures. Generic SDK enhancements and synthetic regressions supplied these capabilities. The exact final tested SDK is recorded in case metadata and SDK evidence.

Cloud acceptance is complete for default budget 15, budget 30 and budget 5: six paired images and 30 worksheet CSV exports passed review and independent validation. The accepted workbook hash and remaining styling differences are recorded in `evidence/visual-review.md`. The result is `acceptable_delta`, with readable icons, four initial Size price rows, eight white-label selected cards, four correctly ordered total segments, complete budget reference labels and correct over/under values.

The original has an initial `Action(Type)=Size` filter. REST requests for other action-filter Type states failed with Tableau 400081 and are archived, not claimed as successful. Product-chart CSV proves the four Size products. The locked Hyper oracle separately proves all 26 raw product prices, while generated native contracts prove the Type-filter initialization and set-action configuration. Selector event execution is outside the declared REST scope. A windows-only source comparison copy exposes existing worksheets without changing data, filters, calculations or layout; its hashes are in `evidence/export-provenance.json`. No browser menu, click or hover was executed, and no pixel equivalence is claimed.

Earlier Cloud rounds revealed icon tint, ordering, currency/glyph, item-card contrast, menu-height and reference-label defects. Superseded captures are archived in scratch and are not used to accept the current artifact. The final build uses untinted Custom shapes, stable type ordering, automatic full-height bars, explicit white selected-item datalabels and native replaceable action-filter initialization. The total label remains partly over its purple segment but is fully legible; title/body/footer spacing, control-caption wording and under-budget color are documented visual differences.
