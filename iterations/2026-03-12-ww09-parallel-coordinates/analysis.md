## Business behavior

normalized independently over the full match domain to [0,1]. Selecting an
opponent emphasizes the matching games without excluding the other games or
changing the normalization. Clearing selection removes the highlight.

## Independent native construction

The author's original wide Hyper is locked and packaged unchanged. Five native
SUM/WINDOW_MIN/WINDOW_MAX calculations normalize total distance, distance per
minute, high-speed distance, high-intensity distance and maximum speed. A native
Measure Names/Multiple Values dual-axis Line composition connects the metrics
for each Game ID. Its second pane paths by Game ID to draw the five vertical
spines. Both axes synchronize. Structured table-calculation addressing includes
Game ID and the highlight-dependent colour/width fields to prevent accidental
normalization within selected/unselected partitions.

reported to the coordinator as generic composition gaps; root implements and
