# Fiscal-year performance reporting

Article: Donna Coles, 2020-06-27. Official challenge: 2020 WW26, published 2020-06-23 (WordPress post 3776). `inputs/source-lock.json` identifies the article, original workbook and extracted accounting Hyper.

The 800 x 500 build starts with `TWBEditor("")` and reads only 5,582 locked accounting rows. Fiscal years start in October. Sales includes accounts beginning with 5; OPP includes prefixes 5 or 696, matching the author calculation. The independent raw-row oracle determines latest month 2020-05, current FY start 2019-10 and prior FY start 2018-10. It checks complete current/prior FYTD aggregates and both 20-month series (12 previous, 8 current). Current Sales is $2,229,528,491.50 and OPP $2,849,913,515.75.

The integer comparison parameter selects budget or prior FYTD. Its native alias and allowed-member aliases expose readable choices. Budget inputs are million-dollar amounts; references use one aggregate parameter value rather than repeating it per accounting fact. Exact ratios determine red below -5%, teal above 5%, and yellow within the inclusive interval. Default budgets 2300/3000, prior-year comparison and low/high budgets exercise reference and colour behavior. Default OPP is below -5% even though its displayed percentage rounds to -5.0%, and must remain red. Native parameter-controlled container visibility removes budget controls in prior-year mode.

Two monthly trends retain October-to-September order, all twelve abbreviated month headers, fiscal-year colours, synchronized hidden axes, average references and latest-point markers. Metric cards contain narrow coloured FYTD bars, separate black-bordered difference KPIs and monthly trends. Foreground one-pixel gray edge zones preserve the outer card outlines when the budget visibility container is shown or hidden. The latest marker uses a smaller native size to reproduce the author rendering rather than copying an author size value whose generated pane rendered much larger.

The released SDK 56377 lacked fiscal-date property authoring. A generic fiscal setter was implemented and synthetically tested; public calls before and after chart creation synchronize native datasource-dependency copies. The generated physical date field preserves fiscal-year-start 10 in every dependency. No author workbook is read by the builder.

Initial captures were rejected for unreadable KPI labels and oversized latest markers. The KPI format contained damaged Unicode characters, producing invalid native numeric formatting and `########`. The builder now uses Python Unicode escapes for the exact author triangle/currency format, and the verifier asserts it exactly. Old complete captures remain under scratch for diagnosis; new evidence must bind the replacement artifact.

REST validation checks all 16 author diagnostic measures (current, prior and budget branches) and all 10 replica selected-comparison measures, plus each available bar/KPI value, all 20 monthly aggregates and latest markers, and both legend member sets. CSV header whitespace is normalized because the author has a trailing space in its OPP reference caption. Numeric comparisons respect the actual exported decimal precision. Some original triangle glyphs are replaced with U+FFFD by REST; only these glyph-corrupted signed amounts use the independently checked percentage sign from the same KPI row. No malformed number is accepted.

Fresh Cloud acceptance passed for final artifact `fa75e8a405d8410a7086cacf5910ee39c1899d88260ca520cc8c28aec0b16954`. Four paired dashboard states and 72 full worksheet CSVs establish visibility, complete numeric results and layout fidelity. The full paired image review is recorded in `evidence/visual-review.md`, including remaining text and label-placement differences. No browser clicking or hovering is claimed. `evidence/export-provenance.json` binds a source comparison copy whose only transformation exposes hidden worksheet windows; source formulas, filters, data and layouts remain unchanged.
