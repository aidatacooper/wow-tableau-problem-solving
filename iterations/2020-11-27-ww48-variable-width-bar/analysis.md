# Can you create a variable width bar chart?

Article 2020-11-27; official challenge 2020-11-25 (2020 WW48).

Analyzed author TWBX in scratch only; builder starts with TWBEditor empty and reads extracted inputs plus public SDK.

94333 attendance facts, 17 sessions including 2 null-location breaks. CountD attendees for height; duration minutes/(24*60) on native left-aligned Bar size encodings for widths.
